# User Guide (Panduan Pengguna)

Folder ini untuk dokumen panduan pemakaian aplikasi yang ditujukan ke **client/end-user** — beda audiens dari 3 folder lain di root repo ini:

- [`erd/`](../../erd/) — requirement & technical design, buat developer.
- [`notes/`](../../notes/) — catatan sesi kerja (human & AI), internal tim.
- [`testing/`](../../testing/) — Test Plan/UAT Script, buat tester internal (checkpoint & prosedur verifikasi, bukan tutorial pakai aplikasi).

Isi folder ini harus:
- Bahasa awam, fokus "cara pakai fitur X" — bukan istilah testing (checkpoint, "hasil yang diharapkan"), bukan istilah teknis internal (nama model, field Python).
- Aman untuk di-share langsung ke client — jangan campur dengan draft/catatan internal.

Status: **belum ada isinya** — folder ini baru dibuat sebagai tempat, kontennya menyusul kalau/ketika User Guide mulai dibangun.
